# UI Enhancement Prompts

## 1. Habit-Themed Backgrounds
- **Current State**: The background uses abstract scientific shapes or random patterns.
- **Request**: Redesign the background to be more thematic and aligned with the habits users are trying to quit (e.g., tobacco, alcohol, drugs, weed, pornography, etc.). 
- **Goal**: Create a visual environment that feels more relevant to the "vices" being overcome, rather than generic science/shapes.

## 2. Dynamic Color Theme Switcher
- **Requirement**: Implement 3-4 distinct color theme options for the entire UI.
- **Implementation**:
    - Add a floating toggle button (fixed on the right or left side) that remains accessible while scrolling.
    - Clicking the button should cycle through the themes.
    - Every component (Landing sections, App cards, UI primitives) should respond to the theme change immediately.
- **Goal**: Allow the user to review all components in different color palettes and choose the one that feels most "premium" and effective.

## 3. Component Visibility & Variants
- **GlassCard Variants**: Ensure that the "GlassCard Variants" section (and all other showcases) are clearly visible and well-organized across all themes.
- **Goal**: A high-fidelity review of how each design primitive looks under different color and background conditions.
